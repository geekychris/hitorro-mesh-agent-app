# Hitorro Mesh Agent App

Spring Boot deployable for a Hitorro Mesh agent — wires MeshAgent + LocalTable providers (NDJSON, Kafka, NATS JetStream, RocksDB) + heartbeat/metrics + auto-configured MeshTransport into a fat jar ready to run on any host, Kubernetes pod, or Orion node.
